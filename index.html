Consecutivos de cotizaciones y despachos
Guardado automático de datos

Cada vez que grabas algo (una venta, una compra, un cliente...) los datos se guardan solos en la base de datos de esta aplicación y en este navegador.

Archivo de datos en tu computador

Elige la carpeta (por ejemplo la de las copias de seguridad). Se crea y actualiza el archivo cotizador-datos.json en cada grabación. Al abrir de nuevo el aplicativo, si ese archivo es más reciente, se cargan sus datos.

Copia de seguridad

La copia incluye productos, clientes, proveedores, ventas, compras, inventario, caja, configuración y fotos de comprobantes. Restaurar reemplaza todo lo que hay ahora.
